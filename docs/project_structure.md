## Boundaries

[Experiment Results and Decisions](experiment_log.md) is the manually maintained
research record. It links to immutable completed artifacts and labels snapshots
of running experiments separately; live progress remains in each run's JSON files.

There is no import path to the retired GitHub-original or repair code. The
old runtime, model versions, diagnostics, preparation scripts, configs and
tests are removed, including generated bytecode in those directories.
Existing artifacts are read-only history, not additional live project versions.

`paper_method` currently implements the image-input core. Underspecified
multimodal fusion is not invented. The method contract records each equation
mapping, reconstruction choice and limitation. Historical checkpoints are
rejected by the new checkpoint format.

The retained dataset is `data/processed/glaucoma_rerun_v1/`. Keeping this fixed
isolates the first new-model test from simultaneous changes to reports and splits.
It is not a recovered paper split. This adapter does not require the retired
preparation scripts; their past snapshots remain in historical artifacts.

## Commands

```bash
bash experiments/paper_method/test.sh
bash experiments/paper_method/run.sh --check
bash experiments/paper_method/run.sh --accept-reconstruction
```

Output: `artifacts/paper_method/image_core_seed123/`. The first command runs
synthetic tests only. The second never constructs a model. Only the third starts
user-run training and evaluation; it acknowledges `paper_method_contract.md`.

`--train-only` skips test generation. `--epochs`, `--batch-size` and `--seed`
change a fresh run; `--run-dir` must be a new directory. Existing data/results
are never overwritten or automatically removed.
